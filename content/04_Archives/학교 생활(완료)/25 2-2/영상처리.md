## 세부 파일: 과제2 개별 진행 과정

#### 모델 사용

- ResNet-101 (Encoder) + LSTM with Attention

파일 추가

- `main.py` 파일 추가
    1. 경로 및 하이퍼파라미터 설정
    2. 단어 사전 구축
    3. 데이터셋, 데이터로더 준비
    4. 모델 초기화 (및 학습)
        - Encoder
        - Attention
        - Decoder
    5. 캡션 생성
    6. 기존의 점수 평가 파일(`compute_metrics.py`) 실행

#### 발전 과정

함수 수정: `generate_caption()`

1. 단어 선택 알고리즘 변화: greedy search → beam search
    - greedy search: 단어 선택 시마다 가장 확률이 높은 단어 1개씩 선택하여 문장 완성
    - beam search:
        - 단어 선택 시마다 가장 확률이 높은 k개의 단어(후보)들을 선택
        - 문장 완성 시 각 단어의 선택 확률(로그 확률, 음수)을 모두 더함, 가장 높은 점수의 문장 선택
(*beam size*(k=3), *max_len*=20)
2. 문장 길이(Length)에 따른 패널티 조절
    - 문장이 길어질수록 점수가 낮아지는 문제 해결
        - 문장 점수를 문장 길이(*Length)*의 거듭제곱(*alpha=0.7*)으로 나눔
    - 길이 제한 완화 (*max_len+=10*)
3. Fine-tuning 적용 및 학습용 이미지 변환 과정 추가
    1. 마지막 레이어에 대한 파인 튜닝 실행
    2. 다양한 이미지 변환에 대해 학습하여 일반화 성능 향상 목표
4. 문장 길이에 대한 가중치 수정 (alpha 0.7 → 1.3)
    - 길고 상세한 문장의 선택 확률 증가 유도
- 인코더의 상위 블록을 선택적으로 학습시키는 파인 튜닝을 수행함으로써 이미지 캡셔닝 태스크에 최적화된 시각적 특징을 추출하도록 유도하였다. 사전 학습된 시각 지식을 보존하면서 새로운 데이터셋에 적응시키기 위해 인코더에는 디코더보다 낮은 학습률을 부여하는 차등 학습 전략을 채택하였다. 학습 시 이미지에 확률적으로 다양한 변환 효과를 적용하여 모델이 특정 훈련 이미지에 과적합되지 않고 미검증 데이터에서도 안정적인 성능을 발휘하도록 하였다.

    - `pip install pandas`

- **결과 예시:**

#### **2.2. 기술 문서**

프로젝트의 기술적 전문성을 입증하기 위해 <u>모델의 구조</u>, <u>평가 지표의 이론적 배경</u>을 상세하게 설명해야 합니다.

#### **프로젝트 소스 폴더 구조**

```plain text
C:.

|   +---TRAIN
|   |   \---images

```

- `**data**`** 폴더:** VLM 모델의 학습(TRAIN) 및 검증(VAL)에 사용된 이미지와 캡션 데이터(`train.csv`, `val.csv`)가 위치하는 디렉토리입니다.
- `**metrics**`** 폴더:** 모델의 성능을 정량적으로 평가하기 위한 스크립트(`compute_metrics.py`)와 평가 결과(`metrics.txt`)가 저장되는 디렉토리입니다.

#### **데이터셋 구성**

| 데이터셋 종류 | 이미지 수 | 캡션 수 |
| --- | --- | --- |
| TRAIN | 24,000장 | 24,000개 |
| VAL | 3,000장 | 3,000개 |

#### **성능 평가지표 분석**

프로젝트 성과 측정에 사용된 3가지 핵심 지표(BLEU-4, METEOR, CIDEr-D)의 이론적 배경과 코드 내 구현 방식을 설명해야 합니다.

- **BLEU-4:** 생성된 문장과 정답 문장 간의 n-gram(4-gram) 중복도를 측정하여 문장의 유창성을 평가합니다. `nltk` 라이브러리의 `corpus_bleu` 함수로 계산되었습니다.
- **METEOR:** 정밀도(Precision)와 재현율(Recall)의 조화 평균을 기반으로 동의어, 형태소까지 고려하여 문장의 정확성을 평가합니다. `nltk`의 `meteor_score` 함수로 계산되었습니다.
- **CIDEr-D:** 생성된 캡션이 다른 참조 캡션들과 얼마나 유사한지를 TF-IDF 가중치를 통해 평가하여 희소성과 중요도를 함께 고려합니다. `pycocoevalcap` 라이브러리의 `Cider` 클래스로 측정되었습니다.

#### **2.3. 회의록**

팀의 체계적인 협업 과정을 입증하기 위해 단순한 회의 내용 나열이 아니라, 프로젝트 기간 동안의 주요 논의, 문제 해결 과정, 의사결정 흐름을 투명하게 보여주어야 합니다.

회의록은 모델 아키텍처 선정 등 주요 마일스톤을 중심으로 시간 순서대로 요약 정리해야 합니다. 각 요약에는 아래 요소가 일관된 형식으로 명확히 기술되어야 합니다.

- **날짜, 참석자, 주요 안건, 결정 사항**

#### **2.4. 참고 문헌**

'참고 문헌' 섹션은 프로젝트가 신뢰할 수 있는 학술적, 기술적 자료에 기반했음을 증명하고, 기술적 선택의 타당성을 뒷받침하는 중요한 근거입니다.

프로젝트 진행 중 참고한 모든 외부 자료(논문, 기술 블로그, 공식 문서 등)를 목록으로 작성해야 합니다. 전문성을 높이기 위해 APA 또는 MLA와 같은 일관된 인용 스타일을 사용하여 체계적으로 정리하는 것을 권장합니다.

        - (+ Localization) 단일 객체 위치 → Bounding Box 로 표시
    2. Object Detection (객체 탐지)
        - 여러 객체 위치 → Bounding Box 로 표시, 클래스 분류
        - (Tracking) 연속된 프레임 상에서의 위치 추적
    3. Image Segmentation (이미지 분할)
        - 객체의 실제 모양 찾기: 픽셀 단위 (확대) 분석 → 경계를 정확하게 구분
    4. Recognition (인식)
↔ Classification (분류)
        - 같은 카테고리(Classification) 안에서 *각자의 정체성*(Recognition) 파악
ex) *옆집* 강아지, *갤럭시 S25* 스마트폰
↔ Object Detection (객체 탐지)
![[image 2.png]]
    5. Generation (생성)
        - 데이터 바탕 → 새로운 (실제 존재하지 않았던) 데이터 생성
        - ex) 이미지 생성, 영상 복원, 스타일 변환, 이미지↔텍스트 변환

- [x] 인공지능의 이해
    - 개념: 컴퓨터가 사람처름 생각하고 판단하게 만드는 기술 (> ML + DL)
    - 영상처리와의 관계: 최적의 $f (x → y)$ 를 만드는 과정 (입력 → 원하는 결론)
    - (과거의 프로그래밍) 명시적 프로그래밍
        - 주어진 조건에 따라 동작
(ex: 조건1: 색상 유사 여부, 조건2: 모양 유사 여부, …)
        - 한계
            - 조건 多 → 정확도 下
            - 데이터를 잘 표현하는 $f$ 찾는 과정 필요
    - (현재의 프로그래밍) 머신러닝 (ML)
        - ~~조건(X)~~, 데이터, 경험(O)
        - 종류
            1. 지도 학습(Supervised): label(ed) data
                1. 준 지도학습(Semi-)
                2. 자기 지도 학습(Self-)
            2. 비지도 학습(Unsupervised): 無-label data (Clustering)
            3. 강화 학습(Reinforcement): 정답에 가까울수록 더 많은 보상 지급
        - 용어
            - 특징(Feature), 예측(Prediction), 손실(Loss, 예측과의 차이)
            - 일반화(Generalization) → (Over/Under)fitting
    - 머신러닝 (ML) vs 딥러닝 (DL)
        - **머신러닝:** 사람이 직접 특징(Feature)을 정의하고 ,이를 추출하도록 컴퓨터에게 학습시킴.
        - **딥러닝:** 컴퓨터가 스스로 데이터에서 특징을 추출하고 고차원적인 표현을 학습. 데이터가 많고 복잡할수록 성능이 뛰어남.

### 6장 후반. 인공신경망과 학습 원리

- [x] 퍼셉트론 (Perceptron)
    - 인공 신경망을 구성하는 단위. <u>일차함수</u> 값을 계산한 뒤 <u>활성화 함수</u>를 거쳐 출력 결정.
$y=sum(x_1w_1, x_2w_2, ...)+b$
    - **활성화 함수 (Activation Function):** 신경망에 비선형성을 부여하여 복잡한 문제를 풀 수 있게 함. (Sigmoid, ReLU, Softmax 등)
![[image 3.png]]
    - 인공신경망 (Artificial Neural Network) 구조**:** 입력층(Input) $\rightarrow$ 은닉층(Hidden) $\rightarrow$ 출력층(Output)으로 구성. 은닉층이 2개 이상(MLP)이면 심층 신경망(DNN)이라 칭함 (↔ ANN).
- [ ] 신경망 학습
    1. **순전파**: 입력 → 출력 과정에서 <u>예측값(o) 계산</u>
    2. **Loss** 계산: $Loss = (o-y)^2$
    3. **역전파**: 출력 → 입력 과정에서 기울기<u>(w) 업데이트</u>
        - <u>기울기 계산</u>: 출력 시 <u>Loss 줄이는 것</u>을 목표로 함 → w에 대한 Loss의 변화량 계산
            - <u>연쇄 법칙</u>: $\frac{dLoss}{dw} = \frac{dLoss}{do} \times \frac{do}{dz} \times \frac{dz}{dw}$
        - <u>가중치 업데이트</u>: 최적화 알고리즘 사용 $→ w -= \alpha \times \frac{dLoss}{dw}$
    - 반복
        - 1 순전파 → 2 Loss 계산 → 3 역전파
        - 상황: 전체 학습 데이터가 **10,000개**이고, **Batch Size를 10**으로 설정한 경우.
            - **Batch Size:** **10** (한 번에 10개의 데이터를 보고 학습).
            - **Iteration:** **1,000** (10,000개의 데이터를 다 보려면 10개씩 1,000번 반복해야 함).
            - **Epoch:** 1,000번의 Iteration이 끝나면 **1 Epoch** 완료.
- [ ] 최적화
    - **경사 하강법 (Gradient Descent):** 손실 함수의 기울기를 따라 오차가 최소화되는 지점(최적의 파라미터)을 찾아가는 방법.
        - 문제1: 전역 최소값(Global Minimum) vs 국소 최솟값 (Local Minima)
        - 문제2: 변곡점
        - 문제3: 적절하지 않은 학습률 → local minima / 변곡점 발생 가능
    - **주요 옵티마이저:**
        - **SGD:** 확률적 경사 하강법. 빠르지만 진동 가능성 존재.
        - **Adam:** 모멘텀(관성)과 적응형 학습률을 결합하여 빠르고 안정적인 학습 수행.

### 7장. CNN

- [ ] 기존 MLP 의 한계
    - 픽셀 선형 배치 → 픽셀 간 공간적 정보(위치, 관계 소실)
    - 입력 크기 증가에 따라 과도하게 가중치 수 증가 → 연산 난이도 上, 과적합 발생
- [ ] CNN의 핵심 특징
    - DNN + (Convolution + Pooling) Layer
    - Convolution Layer: 특징 맵(Feature Map) 생성.
        - <u>특징 추출</u> (Feature Extraction): 하나의 필터(Kernal)을 사용해 이미지 전체를 훑으며 (Sliding Window) 이미지의 국소적인 특징 추출
        - <u>파라미터 공유</u>: 하나의 필터가 동일한 가중치 사용 → 파라미터 수 감소
    - Pooling Layer: 특징 맵의 크기를 줄여 (Max/Average) 연산량 감소, 정보 요약
        - <u>공간적 불변성</u>: 사물의 위치가 바뀌어도 동일한 특징 인식 가능
        - 특정 영역 내에서 가장 큰 값만 남기는 **Max Pooling,** 평균값을 쓰는 **Average Pooling**을 주로 사용
    - **Fully Connected Layer:** 추출된 특징을 바탕으로 최종 분류 수행.
        - **Flatten:** 2, 3차원의 특징 맵 → 1차원 벡터
        - 벡터를 바탕으로 각 클래스에 대해 속할 가능성(확률) 계산 (softmax 함수 → 합 1)

### 7장 후반. CNN 응용, 분류 및 객체 검출

- [ ] <u>**이미지 분류**</u> (1 Classification)
    1. 이미지가 CNN에 입력됩니다.
    2. Conv, Pooling 층을 거치며 이미지의 특징(**Feature)** 추출됩니다.
    3. 마지막 FC 층에서 이 특징들을 바탕으로 "이것은 고양이일 확률 90%, 개일 확률 10%"와 같이 계산하여 **가장 높은 확률의 클래스로 분류**합니다 .

- [ ] <u>**객체 검출**</u> (3 Object Detection) (영역 찾기 + 분류)
    - **R-CNN 계열 (2-Stage):** 먼저 물체가 있을 법한 영역(Region Proposal)을 찾은 뒤, 그 영역에 대해 CNN으로 분류를 수행합니다. 정확도는 높지만 속도가 느립니다.
    - **Fast / Faster R-CNN:** R-CNN의 속도 문제를 개선하기 위해 이미지를 한 번만 CNN에 통과시켜 특징 맵을 만든 후, 그 위에서 영역을 찾거나(RPN) 분류하는 방식을 사용하여 속도를 획기적으로 높였습니다.
    - **1-Stage 모델 (YOLO, SSD):** 영역 찾기와 분류를 한 번의 과정으로 동시에 수행하여 매우 빠른 속도를 자랑합니다 .

- [ ] 평가 지표 (Metric)
- **Pixel Accuracy (픽셀 정확도):**
    - **의미:** 전체 픽셀 중에서 올바르게 분류된 픽셀의 비율 .
    - **단점:** 배경이 대부분이고 객체가 작은 경우(클래스 불균형), 배경만 맞춰도 점수가 높게 나와 성능을 왜곡할 수 있음.
- **IoU (Intersection over Union):**
    - **의미:** 정답 영역과 예측 영역의 **교집합(Intersection)**을 **합집합(Union)**으로 나눈 값.
    - **특징:** 세그멘테이션에서 가장 기본적이고 엄격한 지표. 두 영역이 완벽히 겹치면 1, 아예 안 겹치면 0이 됨.
- **mIoU (mean IoU):**
    - **의미:** 존재하는 모든 클래스에 대해 각각 IoU를 계산한 뒤, 이를 평균 낸 값.
    - **특징:** Semantic Segmentation에서 가장 널리 사용되는 표준 지표.
- **Dice Coefficient (F1-Score):**
    - **의미:** IoU와 유사하며, 정밀도(Precision)와 재현율(Recall)의 조화 평균인 F1-Score의 세그멘테이션 버전 .
    - **활용:** 주로 의료 영상 분야에서 자주 사용됨.

> [!note]+ 5장. 패턴과 특징
> ---
> 
> 패턴 (Pattern)
> 
> - **정의:** 정해진 규칙이나 조건에 따라 정기적으로 반복되는 현상. 형태, 색상, 질감, 구조 등 특정 특성을 반복적으로 나타내는 요소나 구조.
> - 이미지의 일정 부분에서 일정하게 나타나는 속성 (예: 얼굴 이미지에 눈, 코, 입 등 특정 형태와 구조가 반복적으로 나타남).
> - 사물의 본질적 특징을 파악하고 분류하는 데 중요한 역할.
> 
> 패턴 인식 (Pattern Recognition)
> 
> - **정의:** 데이터 내의 규칙성이나 패턴을 식별하고 해석하는 것.
> - 복잡한 데이터 세트에서 의미 있는 정보를 추출하여 의사 결정, 예측 또는 분류를 하는 것을 포함.
> - 일반적으로 2차원 이미지를 분석하고 그 안에서 미리 지정된 관심 하위 영역을 인식하려는 시도 (즉, 레이블을 지정하려는 시도).
> - 반복되는 특성을 파악하여 다음에 올 데이터나 상황을 예측.
> - 시간적, 순차적 패턴을 학습하여 미래 데이터를 예측.
> 
> ---
> 
> 특징 (Feature)
> 
> - **정의:** 데이터 속에서 특정 객체나 패턴을 구분하는 데 유용한 정보 또는 속성. (예: 얼굴 인식에 눈, 코, 입의 형태와 위치 등).
> - 패턴 인식을 성공하기 위해 특징을 추출하고, 선택하고, 사용하는 과정은 매우 중요함.
> 
> 특징의 종류
> 
> 1. **전역 특징 (Global feature)**
>     - 이미지 전체의 특성을 요약하는 특징.
>     - **히스토그램:** 이미지 내 색상 분포 요약.
>     - **모양 특징:** 객체의 외곽이나 형태.
>     - **질감 특징:** 이미지에 반복적으로 나타나는 패턴 (예: 의료 영상에서 조직의 질감).
> 2. **지역 특징 (Local feature)**
>     - 이미지 내 특정 위치나 픽셀 그룹과 관련된 특징.
>     - 객체의 위치가 변해도 특징을 유지하는 **불변성(Invariant)**을 갖고 있음.
> 
> ---
> 
> 패턴 추출 기법
> 
> - **허프 변환 (Hough Transform)**
> - **Histogram of Oriented Gradients (HOG)**
> - **Scale-Invariant Feature Transformation (SIFT)**
> - **Speeded-Up Robust Features (SURF)**

> ### **영상처리의 주요 분야**
> 
> - **Classification (분류)**
>     - 입력 이미지나 영상을 특정 클래스나 범주에 할당하는 작업.
>     - 데이터의 종류를 파악하는 데 기본적인 역할.
>     - **단일 객체 분류:** 1개의 객체가 있는 사진의 클래스를 분류 (예: CAT)
> - **Classification + Localization**
>     - 단일 객체의 위치를 찾아 해당 위치를 Bounding Box로 표시.
>     - Object detection 기술의 전신.
> - **Object Detection (객체 검출)**
>     - 여러 객체가 있는 이미지에서 각 객체의 위치를 찾고 분류.
>     - 객체마다 Bounding Box를 할당 (예: CAT, DOG, DUCK).
>     - 응용: 자율주행, CCTV 감시 등.
>     - **Object Tracking (추적):** 영상에서 연속된 프레임 상의 객체 위치를 추적5.
> - **Object Recognition (객체 인식)**
>     - 영상 내 특정 개체나 특징을 식별하고 정체성을 파악.
>     - **Classification vs Recognition:** 카테고리 분류(Classification)를 넘어 해당 카테고리 내에서 정확한 정체성 파악(Recognition)
>     - 예: 얼굴 인식, 지문 인식 (같은 Class 내 개인별 특성 파악).
> - **Image Segmentation (이미지 분할)**
>     - 객체의 실제 모양을 찾는 기술 (Object detection의 발전된 형태).
>     - 이미지의 각 픽셀을 특정 클래스에 할당하여 객체의 경계를 정확하게 구분.
> - **Generation (생성)**
>     - 학습된 패턴을 바탕으로 새로운 데이터를 생성.
>     - **주요 분야:**
>         - 이미지 생성 (예: 사람 얼굴 생성)
>         - 영상 복원 및 보정 (슈퍼 레졸루션)
>         - 스타일 변환 (Style Transfer)
>         - 이미지-텍스트 변환 (DALL-E 등)
> 
> ### **인공지능(Artificial Intelligence)**
> 
> - **정의:** 컴퓨터를 사람처럼 생각하고 판단할 수 있도록 만드는 기술
>     - 머신러닝, 딥러닝을 포함하는 포괄적인 개념
> - **영상처리와 인공지능의 관계 (**$y=f(x)$**)**
>     - $x$: 입력 (예: 강아지 사진).
>     - $y$: 출력/결론 (예: 강아지 Class).
>     - $f$: 입력을 적절히 분류하여 결론을 짓게 만드는 모델의 함수.
>     - **과거의 영상처리 (명시적 프로그래밍):** 사람이 패턴을 파악하고 조건문(규칙)을 직접 작성. 조건이 복잡해지면 한계 발생
>     - **현대의 인공지능:** 데이터로부터 특징을 추출하고 학습하여 데이터를 가장 잘 표현하는 함수 $f$를 자동으로 찾음
> 
> ### **학습 방법 (Learning Methods)**
> 
> - **머신러닝(Machine Learning):** 명시적 규칙 코딩 없이 데이터(경험)로부터 파라미터를 자동 학습
>     - **Supervised Learning (지도 학습):** 입력-정답(라벨) 쌍으로 학습
>     - **Unsupervised Learning (비지도 학습):** 정답 없는 데이터를 학습, 비슷한 특징끼리 군집화(Clustering)
>     - **Semi-supervised / Self-supervised Learning:** 소량의 라벨 데이터 활용 또는 데이터 자체에서 문제를 만들어 학습
>     - **Reinforcement Learning (강화 학습):** 행동에 대한 보상을 통해 학습 (예: 알파고)
> 
> ### **주요 용어 및 비교**
> 
> - **용어 정리:**
>     - **특징(Feature):** 데이터를 잘 표현하기 위해 추출된 속성 (색상, 모양 등)
>     - **예측(Prediction):** 모델에 새로운 데이터를 입력해 결과를 얻음
>     - **손실(Loss):** 예측값과 실제값 사이의 차이
>     - **일반화(Generalization):** 보지 못한 데이터에서도 높은 성능을 유지하는 능력
> - **머신러닝 vs 딥러닝** 
>     - **머신러닝:** 사람이 지정한 특징(Feature extraction)을 컴퓨터가 학습
>     - **딥러닝:** 컴퓨터가 **스스로 특징을 학습**하고 고차원적 표현을 생성(End-to-End learning); 데이터 양이 많고 복잡할수록 성능이 뛰어남.
>

> [!note]+ 6-1장. 인공신경망과 퍼셉트론
> ---
> 
> 인공신경망(ANN)의 기초 단위인 퍼셉트론, 활성화 함수, 그리고 신경망의 구조와 학습 사이클을 다룹니다.
> 
> ### **인공신경망 (Artificial Neural Network)**
> 
> - **개념:** 뉴런들이 여러 층(Layer)으로 연결된 구조
> - **퍼셉트론 (Perceptron):**
>     - 인공신경망을 구성하는 기본 단위 (Artificial Neuron)
>     - 생물학적 뉴런(수상돌기, 축삭돌기 등)의 동작 과정을 모델링
>     - 다수의 입력($x$)에 가중치($w$)를 곱해 더한 값($Linear Operation$)을 활성화 함수에 통과시켜 출력($y$)을 결정
>     - **수식:** $y = f(w^T x + b)$
>     - **결정 경계:** $w \cdot x + b = 0$은 데이터를 구분하는 직선(또는 초평면) 역할을 함
> 
> ### **활성화 함수 (Activation Function)**
> 
> - **역할:** 입력 신호를 **비선형(Non-linear)** 함수로 변환하여 신경망이 복잡한 패턴을 학습할 수 있게 함
>     - 선형 함수만 사용하면 여러 층을 쌓아도 하나의 선형 층과 동일해짐
> - **종류 및 특징**:
>     - **계단 함수 (Step Function):** 퍼셉트론 초기에 사용. 미분 불가능.
>     - **Sigmoid:** 0~1 사이 값. 기울기 소실(Vanishing Gradient) 문제 발생 가능.
>     - **Tanh:** -1~1 사이 값. Sigmoid보다 0에 가까움.
>     - **ReLU:** $max(0, x)$. 계산 효율적, 은닉층에서 가장 많이 사용.
>     - **Softmax:** 다중 클래스 분류의 출력층에 사용 (확률의 합 = 1).**신경망의 구조 (Structure)**
> - **Input Layer (입력층):** 데이터 전달, 계산 없음
> - **Hidden Layer (은닉층):** 데이터 가공, 패턴/특징 추출
> - **Output Layer (출력층):** 최종 예측 결과 생성
> - **구조 구분:**
>     - **Single-layer Perceptron:** 단층 구조.
>     - **MLP (Multi-Layer Perceptron):** 하나 이상의 은닉층이 존재
>     - **DNN (Deep Neural Network):** 은닉층이 2개 이상인 깊은 신경망
> 
> ### **학습 메커니즘**
> 
> - **학습 과정 (Learning Process):**
>     1. 순전파 (Forward Propagation): 출력값 계산.
>     2. Loss 계산: 정답과 예측의 오차 측정.
>     3. 역전파 (Back Propagation): Loss를 줄이는 방향으로 가중치($w, b$) 업데이트.
> - **학습 단위:**
>     - **Batch:** 한 번의 파라미터 업데이트에 사용하는 데이터 묶음
>     - **Iteration:** 1회 업데이트 (Batch size만큼 처리)
>     - **Epoch:** 전체 데이터셋에 대해 한 번 학습을 완료한 상태
> 
> ### **실습 내용**
> 
> - **AND / OR 게이트:** 단층 퍼셉트론으로 구현 가능 (선형 분리 가능)
> - **XOR 게이트:** 단층 퍼셉트론으로 구현 불가능 (비선형 문제), MLP가 필요함
>

> [!note]+ 6-2장. 학습 원리와 최적화 심화
> ---
> 
> 이 파일은 순전파/역전파의 수식적 원리, Chain Rule, 그리고 손실을 최소화하기 위한 최적화(Optimization) 기법을 상세히 다룹니다.
> 
> ### **3.1. Propagation (전파 과정)**
> 
> - **Forward Propagation (순전파):**
>     - 입력($x$)에서 출력($o$)을 얻기 위한 일련의 계산 과정51.
>     - $z = wx + b$ 계산 후 활성화 함수 $f(z)$ 통과.
> - **Back Propagation (역전파):**
>     - 출력과 정답의 차이(Loss)를 최소화하기 위해 가중치를 업데이트하는 과정.
>     - **Chain Rule (연쇄 법칙):** 합성 함수의 미분을 계산하는 규칙. 역전파에서 각 가중치에 대한 기울기(Gradient)를 계산할 때 핵심적으로 사용됨
>     - 수식 예: $\frac{dLoss}{dw} = \frac{dLoss}{do} \cdot \frac{do}{dz} \cdot \frac{dz}{dw}$
> 
> ### **3.2. Optimization (최적화)**
> 
> - **목표:** Loss Function이 최소가 되는 최적의 파라미터(가중치)를 찾는 것
> - **Gradient Descent (경사 하강법):**
>     - 기울기(Gradient)를 계산하여 기울기가 낮은(반대) 방향으로 이동하며 극값을 찾음.
>     - **Learning Rate (**$\alpha$**, 학습률):** 이동하는 보폭의 크기.
>         - 너무 크면: 발산(Divergence) 위험
>         - 너무 작으면: 수렴이 느리고 Local Minima(국소 최저점)에 빠질 위험
> - **Local Minima 문제:** 전체 최소값(Global Minimum)이 아닌 웅덩이(Local Minima)나 변곡점에 갇혀 최적 파라미터로 오인하는 현상
> 
> ### **3.3. 주요 Optimizer (최적화 알고리즘)**
> 
> - **SGD (Stochastic Gradient Descent):** 무작위로 선택한 데이터(Batch)로 업데이트. 빠르지만 진동이 심함
> - **Momentum:** 이전의 기울기(관성)를 누적하여 진동을 줄이고 학습 속도 향상
> - **Adam (Adaptive Moment Estimation):**
>     - Momentum과 적응형 학습률을 결합.
>     - 기울기의 평균(1차 모멘트)과 분산(2차 모멘트)을 모두 사용.
> 
> ### **3.4. MLP 학습 예시 (Calculation)**
> 
> - **설정:** Optimizer는 Gradient Descent, Loss는 MSE(Mean Square Error), 활성화 함수는 Sigmoid 사용
> - **과정:**
>     1. **순전파:** 입력 $\rightarrow$ 은닉층 $\rightarrow$ 출력층 $\rightarrow$ MSE Loss 계산 ($Loss = (o - o_1)^2$)
>     2. **역전파:** Loss를 미분하여 각 가중치($w$)에 대한 변화량($\Delta w$) 계산 (Chain Rule 적용)
>     3. **업데이트:** $w' = w - \alpha \Delta w$

> [!note]+ 7장. Convolutional Neural Network
> ---
> 
> 이 파일은 완전연결층(MLP)의 한계를 극복하기 위해 등장한 CNN의 기본 개념, 주요 레이어(Convolution, Pooling), 그리고 전체적인 구조를 설명합니다.
> 
> ### **특징 추출 (Feature Extraction)**
> 
> - **사람의 시각:**
>     - 망막의 광수용체(원추/막대세포)가 특정 영역(Receptive Field)의 빛을 받아들임.
>     - 시각 정보는 뇌의 여러 층을 거치며 단순한 엣지에서 복잡한 패턴(얼굴 등)으로 통합되고 해석됨.
> - **MLP/DNN의 한계:**
>     - **공간 정보 소실:** 2차원 영상을 1차원으로 변환(Flatten)하여 입력하므로, 픽셀 간의 공간적 관계나 위치 정보를 학습할 수 없음 (예: 물체가 이동하거나 회전하면 다른 패턴으로 인식).
>     - **파라미터 과다:** 입력 차원이 클 경우(예: 300x300x3), FC Layer의 파라미터 수가 급격히 증가하여 과적합(Overfitting) 위험이 커짐.
> 
> ### **합성곱 (Convolution)의 특징**
> 
> - **파라미터 공유 (Parameter Sharing):**
>     - 하나의 필터(커널)가 이미지의 모든 위치에서 동일한 가중치를 사용하여 특징을 추출.
>     - FC Layer 대비 학습해야 할 파라미터 수가 획기적으로 줄어듦.
> - **공간적 불변성 (Spatial Invariance):**
>     - Sliding Window 방식을 통해 패턴의 위치가 달라져도 동일한 특징을 탐지 가능.
> 
> ### **CNN의 주요 레이어**
> 
> - **Convolution Layer (합성곱 층):**
>     - 입력 특징 맵에 필터를 적용하여 특징을 추출.
>     - **출력 크기:** Feature Map 크기 $\times$ 필터 개수.
>     - **Stride:** 필터가 이동하는 간격 (보폭).
>     - **Logit:** 활성화 함수 적용 전의 출력값.
>     - **Activation:** 주로 ReLU ($max(0, x)$) 사용.
> - **Pooling Layer (풀링 층):**
>     - Feature Map의 크기를 줄여 연산량을 감소시키고, 불변성(Invariance)을 강화.
>     - **Max Pooling:** 영역 내 최댓값 추출.
>     - **Average Pooling:** 영역 내 평균값 추출.
> - **Flatten & Fully Connected Layer:**
>     - 다차원 Feature Map을 1차원 벡터로 변환하여 최종 분류(Classification)를 수행.
> 
> ### **CNN 구조**
> 
> - **블록(Block) 구조:** 일반적으로 `Conv` $\rightarrow$ `Pooling`을 번갈아 쌓아 특징을 추출(Feature Extraction)하고, 뒷단에 `FC Layer`를 배치하여 분류(Classification)를 수행.
> - **End-to-End Learning:** 특징 추출과 분류기 학습을 한꺼번에 진행.

> [!note]+ 7-1장. CNN 응용: 분류 및 객체 검출
> ---
> 
> 이 파일은 CNN을 이용한 이미지 분류 시의 난제와 해결책, 학습 전략(전이 학습), 그리고 객체 검출(Object Detection) 모델들의 발전 과정(R-CNN 계열)을 상세히 다룹니다.
> 
> ### **5.1. 이미지 분류 (Image Classification)와 난제**
> 
> - **정의:** 입력 이미지를 특정 클래스에 할당 (단일 객체 분류).
> - **주요 난제 (Challenges):**
>     - **Occlusion (가림):** 객체 일부가 가려짐 $\rightarrow$ CNN은 국소 특징(Local feature)을 학습하므로 어느 정도 강인함.
>     - **Illumination (조명):** 밝기 변화 $\rightarrow$ **Batch Normalization**과 ReLU로 완화.
>     - **Deformation (변형):** 객체 모양 왜곡 $\rightarrow$ CNN 필터와 Pooling이 강인함을 제공.
>     - **Background Clutter (배경 혼잡):** 배경과 객체가 비슷함.
>     - **Scale / View-point:** 크기 및 시점 변화 $\rightarrow$ Multi-scale 학습 및 **Data Augmentation**으로 해결.
> - **Batch Normalization (배치 정규화):**
>     - 각 층의 출력을 정규화(평균 0, 분산 1)하여 학습 안정성 향상, 기울기 소실/폭발 문제 완화.
> 
> ### **5.2. 손실 함수와 엔트로피**
> 
> - **Entropy:** 불확실성의 정도를 수치화한 것. (예측이 어려울수록 높음).
> - **Cross Entropy Loss:**
>     - 실제 분포(정답, One-hot)와 모델 예측 분포(Softmax 출력) 간의 차이를 측정.
>     - 수식: $Loss = -\sum y_i \log(\text{softmax}(x_i))$.
> 
> ### **5.3. CNN 학습 전략**
> 
> - **Pre-Training (사전 학습):** ImageNet과 같은 대규모 데이터셋으로 일반적 특징을 먼저 학습.
> - **Transfer Learning (전이 학습):** 사전 학습된 모델의 Backbone(특징 추출기)을 고정(Freeze)하고, 출력층(Classifier)만 새로운 태스크에 맞춰 재학습.
> - **Fine Tuning (미세 조정):** 사전 학습된 모델의 전체 레이어 혹은 많은 부분을 낮은 학습률로 재학습.
> 
> ### **5.4. 객체 검출 (Object Detection)**
> 
> - **정의:** 이미지 내 여러 객체의 **위치(Localization, Bounding Box)**를 찾고 **클래스(Classification)**를 분류.
> - **R-CNN (Regions with CNN features):**
>     - **과정:** Selective Search로 2,000개 후보 영역 추출 $\rightarrow$ 각 영역을 CNN에 입력(Crop/Warp) $\rightarrow$ SVM으로 분류 $\rightarrow$ BBox Regression.
>     - **단점:** 속도가 느리고, 연산량이 많으며, 학습 단계가 복잡함.
> - **Fast R-CNN:**
>     - **개선:** 전체 이미지에 대해 **한 번만 CNN 실행** $\rightarrow$ Feature Map 생성.
>     - **RoI Pooling:** Feature Map 상에서 후보 영역을 투영(Projection)하여 고정 크기 벡터 추출.
>     - **Multi-task Loss:** 분류(Softmax)와 위치 보정(Regressor)을 동시에 학습.
> - **Faster R-CNN:**
>     - **핵심:** **RPN (Region Proposal Network)** 도입. Selective Search를 딥러닝 네트워크로 대체.
>     - **Anchor Box:** 다양한 크기와 비율(Scale/Aspect Ratio)을 가진 미리 정의된 박스(9개 등)를 사용하여 후보 영역을 생성.
>     - **구조:** 2-Stage Detector (RPN으로 영역 제안 $\rightarrow$ Fast R-CNN 방식으로 분류).
> - **1-Stage Detector:** YOLO, SSD 등 (속도는 빠르나 상대적으로 정확도는 낮을 수 있음).

> [!note]+ 8장. Image Segmentation & Evaluation
> ---
> 
> 이 파일은 픽셀 단위로 이미지를 분석하는 Segmentation 기술과 이를 구현하는 FCN, U-Net, DeepLab 등의 모델, 그리고 모델 성능 평가를 위한 정량적 지표들을 상세히 설명합니다.
> 
> ### **Image Segmentation (이미지 분할)**
> 
> - **정의:** 이미지를 픽셀 단위로 분석하여 의미를 부여하는 기술.
> - **종류:**
>     - **Semantic Segmentation:** 모든 픽셀에 클래스(카테고리)를 부여. 같은 클래스의 객체끼리는 구별하지 않음 (예: 모든 사람은 같은 '사람' 색상)
>     - **Instance Segmentation:** 객체의 픽셀을 분류하고 개별 ID를 할당. 겹쳐진 같은 클래스의 객체도 서로 다른 것으로 인지함
>     - **Panoptic Segmentation:** Semantic + Instance. 배경(Stuff, 셀 수 없음)은 Semantic으로, 객체(Thing, 셀 수 있음)는 Instance로 처리
> 
> ### **CNN 기반 Segmentation의 발전**
> 
> - **기존 CNN/FC의 한계:**
>     - Fully Connected Layer는 위치 정보를 잃어버리고(Spatial info loss), 입력 이미지 크기가 고정되어야 함
>     - Pooling으로 인해 피처 맵의 크기가 줄어들어 픽셀 단위 예측이 불가능함
> - **FCN (Fully Convolutional Networks):**
>     - FC Layer를 **1x1 Convolution**으로 대체하여 위치 정보를 유지하고 다양한 입력 크기를 허용
>     - **문제점:** 출력 피처 맵(Coarse map)이 입력 대비 작아짐(예: 1/32)
>     - **해결:** Upsampling을 통해 해상도를 복원해야 함 (Dense map)
> 
> ### **Upsampling (해상도 복원) 기법**
> 
> - **Interpolation (보간법):**
>     - **Nearest Neighbor:** 가장 가까운 값을 복사.
>     - **Bilinear:** 인접한 4개 픽셀의 선형 보간.
>     - **Bicubic:** 주변 16개 픽셀을 이용한 2차 방정식 보간
> - **Transpose Convolution (Deconvolution):** 학습 가능한 가중치를 사용하여 역방향 컨볼루션을 수행
> - **Unpooling (Max Unpooling):** Max Pooling 시 저장해 둔 **인덱스(위치)**를 사용하여 값을 복원 (SegNet에서 사용)
> - **Pixel Shuffle:** 채널 정보를 공간 차원으로 재배치하여 해상도 증가
> 
> ### **주요 아키텍처 (Architectures)**
> 
> - **Encoder-Decoder 구조:** 영상을 압축하여 특징 추출(Encoding) 후 다시 복원(Decoding)하는 구조
> - **SegNet:** Encoder-Decoder 구조. Max Pooling의 인덱스를 Decoder로 전달하여 Unpooling 수행
> - **U-Net:**
>     - 대표적인 Encoder-Decoder 구조.
>     - **Skip Connection:** Encoder의 고차원 정보를 Decoder의 피처 맵과 **Concatenation(연결)**하여 디테일 복원
> - **DeepLabv3+:**
>     - **Atrous Convolution (Dilated Conv):** 연산량 증가 없이 Receptive Field를 확장
>     - **Depthwise Separable Conv:** 연산량을 획기적으로 줄임
>     - **ASPP (Atrous Spatial Pyramid Pooling):** 다양한 크기의 Receptive Field 정보를 통합
> 
> ### **Evaluation Metric (평가 지표)**
> 
> - **Confusion Matrix (오차 행렬):** TP(정답), FP(오답-긍정예측), FN(오답-부정예측), TN(정답-부정)
> - **기본 지표:**
>     - **Precision (정밀도):** 모델이 True라고 한 것 중 실제 True의 비율 ($\frac{TP}{TP+FP}$)
>     - **Recall (재현율):** 실제 True인 것 중 모델이 찾은 비율 ($\frac{TP}{TP+FN}$)
>     - **Accuracy (정확도):** 전체 중 정답 비율. 데이터 불균형 시 왜곡됨
>     - **F1-Score:** Precision과 Recall의 조화 평균
> - **Object Detection 지표:**
>     - **IoU (Intersection over Union):** 교집합/합집합. 예측 박스와 정답 박스의 겹치는 비율
>     - **AP (Average Precision):** PR Curve(Precision-Recall 곡선) 아래의 면적.
>     - **mAP (mean AP):** 모든 클래스 AP의 평균
> - **Segmentation 지표:**
>     - **Pixel Accuracy:** 픽셀 단위 정확도.
>     - **mIoU (mean IoU):** 모든 클래스의 IoU 평균. 가장 널리 쓰임
>     - **Dice Coefficient:** F1-Score와 유사, 의료 영상에서 주로 사용

> ### **7.1. Sequence to Sequence (Seq2Seq)**
> 
> - **개념:** 하나의 시퀀스(입력)를 받아 다른 시퀀스(출력)를 생성하는 모델 (예: 번역, 요약) .
> - **기존 방식 (RNN):**
>     - 순환 신경망(RNN)을 사용하여 시퀀스를 순차적으로 처리.
>     - **인코더:** 입력을 고정된 크기의 **Context Vector**로 변환.
>     - **디코더:** Context Vector를 기반으로 출력 시퀀스 생성 .
> - **RNN의 한계:**
>     - **장기 의존성(Long-Term Dependency) 문제:** 시퀀스가 길어질수록 과거 정보가 소실됨.
>     - **기울기 소실(Vanishing Gradient):** 역전파 시 기울기가 사라져 학습이 안 됨.
>     - **순차 처리:** 병렬 처리가 불가능하여 속도가 느림 .
> - **LSTM (Long-Short Term Memory):**
>     - Cell State($c_t$)와 3개의 게이트(Forget, Input, Output)를 도입하여 중요 정보를 장기적으로 기억. RNN의 문제를 완화했으나 여전히 아주 긴 시퀀스에는 한계가 있음 .
> 
> ### **7.2. Attention Mechanism (어텐션 메커니즘)**
> 
> - **등장:** 긴 시퀀스에서의 정보 손실을 막기 위해 중요 부분에 집중(Focus)하는 기법 .
> - **Transformer ("Attention is All You Need", 2017):**
>     - RNN/CNN 없이 오직 Attention만으로 시퀀스를 처리. 현재 모든 LLM(GPT, Gemini 등)의 기반 구조 .
> - **핵심 요소 (Q, K, V):**
>     - **Query (Q):** 질문 (현재 처리 중인 토큰의 정보).
>     - **Key (K):** 인덱스 (입력 시퀀스의 각 토큰이 가진 식별 정보).
>     - **Value (V):** 값 (실제 정보 내용).
>     - **원리:** Q와 K의 유사도(**내적**, Dot-Product)를 계산하여 가중치(Softmax)를 구하고, 이를 V에 곱해 중요한 정보를 강조함 .
>     - **수식:** $Attention(Q, K, V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$.
> 
> ### **7.3. Transformer 구조**
> 
> - **Self-Attention:** 문장 내에서 단어들끼리의 관계(문맥)를 파악 .
> - **Positional Encoding:** 병렬 처리를 위해 순서 정보가 사라지는 것을 방지하고자 위치 정보를 임베딩에 더해줌.
> - **Encoder:** Multi-Head Self-Attention + FFN으로 구성. 문맥 전체를 양방향으로 분석 .
> - **Decoder:**
>     - **Masked Self-Attention:** 미래의 토큰(정답)을 미리 보지 못하게 가림 (Causal Mask).
>     - **Cross-Attention:** 인코더의 출력($E$)을 Key와 Value로 사용하여 입력 원문 정보를 참조 .
> 
> ### **7.4. Computer Vision에서의 Attention (ViT)**
> 
> - **발전:** 초기에는 CNN에 Attention을 결합(SENet, CBAM)하다가, **ViT (Vision Transformer, 2020)**에서 CNN을 완전히 대체함.
> - **ViT 구조:**
>     - **Patch Partition:** 이미지를 픽셀이 아닌 $16 \times 16$ 크기의 **패치(Patch)**로 분할.
>     - **Linear Projection:** 패치를 1차원 벡터(토큰)로 변환 (Embedding).
>     - **CLS Token:** 이미지 전체의 정보를 요약하는 특수 토큰을 추가하여 최종 분류에 사용 .
> - **특징:**
>     - CNN의 국소적(Local) 한계를 넘어 전역적(Global) 관계를 학습.
>     - 대규모 데이터셋(JFT-300M 등)으로 사전 학습했을 때 CNN보다 성능이 뛰어남 (데이터가 적으면 성능 저하) .
> - **SAM (Segment Anything Model):** ViT 인코더와 프롬프트 디코더를 결합하여 범용 세그멘테이션 수행 .
> 
> ### **7.5. Vision Language Model (VLM)**
> 
> - **개념:** 이미지와 텍스트를 동시에 처리하는 멀티모달(Multi-modal) AI (예: 이미지 캡션, 시각적 질문 답변) .
> - **구조:**
>     1. **Vision Encoder:** 이미지를 패치 단위 토큰으로 변환 (ViT, CLIP 등).
>     2. **Multimodal Projector (Bridge):** 비주얼 토큰을 LLM이 이해할 수 있는 텍스트 임베딩 공간으로 투영 (Linear, Q-Former 등).
>     3. **Text Decoder (LLM):** 시각 정보와 텍스트 정보를 결합하여 답변 생성 (Autoregressive) .
> - **대표 모델:** CLIP, BLIP-2, LLaVA .

> ### 1. 필터(Filter)의 개요
> 
> - **정의:** 영상을 구성하는 픽셀 값에 특정한 연산을 적용하여 원하는 효과(잡음 제거, 선명화, 경계 강조 등)를 얻는 기법입니다.
> - **다른 명칭:** 마스크, 커널, 윈도우라고도 불리는 일종의 행렬입니다.
> - **작동 방식:** 이 행렬이 영상 전체를 슬라이딩하며 연산을 수행합니다.
> - **분류:** 공간 영역의 필터링과 주파수 영역의 필터링으로 나눌 수 있습니다.

> ### **3. 공간 영역 필터 (Spatial Domain Filters)**
> 
> - **블러링 필터 (Blurring Filter):** 스무딩을 위한 필터로, 영상을 부드럽게 만들고 잡음을 줄입니다. 1616
>     - **평균값 필터:** 주변 픽셀 값의 산술 평균으로 지정합니다. 가까운 픽셀과 먼 픽셀 모두 같은 가중치를 사용합니다. 17171717마스크 크기가 커질수록 더 흐려집니다. 18
>     - **가우시안 필터:** 가우시안 분포 함수를 근사하여 생성. 중앙과 가까운 영역에 높은 가중치를 부여하여, 먼 픽셀의 영향을 줄입니다. 19191919
> - **양방향 필터 (Bilateral filter):** 경계를 보존하면서 부드럽게 하기 위해 고안된 비선형 필터입니다. 20
>     - 픽셀 간의 **공간적 거리**와 **색상 차이**를 모두 고려하여 필터링합니다. 21
>     - 공간적으로 가깝고 밝기가 유사한 픽셀에만 높은 가중치를 부여하여, 노이즈를 제거하면서도 엣지를 보존합니다. 22
> - **중간값 필터 (Median Filter):** 비선형 필터로, 이웃 값들을 정렬한 뒤 중간값을 선택합니다. 소금 & 후추 잡음 제거에 특화되어 있습니다. 23
> 
> ### **4. 미분 및 샤프닝 필터**
> 
> - **미분 필터 (Differentiation filter):** 영상 내 픽셀의 강도 변화를 강조하는 High Pass Filter입니다. 24
>     - **1차 미분 필터 (Sobel 등):** 밝기의 변화율(기울기)을 계산하여 에지의 위치와 방향을 감지합니다. 경계선이 선처럼 뚜렷하게 표시됩니다. 25
>     - **2차 미분 필터 (라플라시안 필터):** 에지 주변이 양/음 값으로 강조되며, 경계 강조력이 강하지만 잡음도 같이 증폭되고 방향 정보는 없습니다. 26
> - **샤프닝 필터 (Sharpening filter):** 영상을 선명하게 하는 필터로, 고주파 성분을 계수와 곱하여 원 영상에 더해주는 형태입니다. 고주파를 강조하기때문에 노이즈가 있는 경우 노이즈도 함께 증폭될 수 있습니다. 27
> - **LoG (Laplacian of Gaussian):** 가우시안 필터로 잡음을 제거한 후 라플라시안 필터로 에지를 검출하는 결합 필터입니다. 28
> 
> ### **5. 주파수 영역 필터 (Frequency Domain Filters)**
> 
> - **주파수 영역:** 신호나 영상을 진동수(주파수) 성분으로 바꿔서 표현하는 방식입니다. 얼마나 빠른 변화(고주파)와 느린 변화(저주파)가 섞여 있는지를 보여줍니다. 29
>     - **저주파:** 느리고 부드러운 변화 (큰 덩어리, 부드러운 영역) 30
>     - **고주파:** 빠른 변화 (에지, 질감, 노이즈) 31
> - **푸리에 변환:** 시간공간) 영역에서 다루기 힘든 내용을 주파수 영역에서 처리하기 위한 변환 방법입니다. 32
> - **활용:**
>     - 노이즈는 일반적으로 고주파 성분으로 나타나므로, **Low Pass Filter (LPF)**로 제거할 수 있습니다. 33
>     - 가장자리(경계) 부분은 **High Pass Filter (HPF)**를 이용하여 검출할 수 있습니다. 34
>     - 주기적인 패턴의 잡음 제거에 유용합니다. 35

> | 모든 신호 표현 | 압축 가능 |
> | 변질 가능 | 손실 적음 |
> - **학문 분야**: 영상 처리와 컴퓨터 비전의 차이, 그리고 컴퓨터가 인간의 시각을 능가할 수 있는 가능성.
>     - 영상 처리가 어려운 이유
>         - Semantic(이론적)Gap 사람 ≠ 컴퓨터
>         -  영상(3차원) → 컴퓨터(2차원) → (3차원 유추)
>         - 답이 정해지지 않음
>         - 기하학적, 광학적 변화 민감
> - **기본 단위**: 영상의 기본 구성 요소인 픽셀.
> - **컬러 모델**: RGB, CMYK, 밝기/색채 모델의 이해.
>     - 색상의 3속성
>         - 밝기
>         - 생상
>         - 채도
> 
> ### **2. 영상의 구조와 처리**
> 
> - **영상 데이터 구조**: 영상은 픽셀, RGB 값, 그리고 텐서로 구성됨.
>     - 픽셀
>     - RGB(r, g, b)
>     - 텐서(h, w, RGB)
> - **바이너리 이미지**: 흑백으로 표현되는 이미지.
>     - 임계값 기준 1/0
> - **영상 처리의 목적**: 영상을 처리하는 근본적인 이유.
> - **주요 개념**: 밝기와 대비(선명도)의 개념.
> - **개발 환경**: 프로젝트별 관리를 용이하게 하기 위해 가상 환경을 사용하는 이유.
> 
> ### **3. 영상 연산**
> 
> - **영상 처리와 텐서**: 텐서를 활용한 영상 처리.
> - **연산의 종류**:
>     - 점 연산
>     - 영역 연산
>     - 기하 연산
> - **기하 연산**: 기하 연산의 사용 목적 및 앨리어싱 현상 (CNN은 시험 범위에서 제외).
> - **바이너리 이미지**: 바이너리 이미지의 사용 이유와 0과 1을 나누는 기준.
> 
> ### **4. 잡음과 필터**
> 
> - **잡음 (Noise)**: 영상에 발생하는 잡음의 개념.
> - **필터**: 잡음 제거 등을 위한 필터의 종류.
> - **모폴로지 연산**: 영상의 형태학적 처리 기법.
