## 세부 파일: 중간

1. pandas 라이브러리

| **구분** | **list (리스트)** | **Series (시리즈)** |
| --- | --- | --- |
| **소속** | 파이썬 기본 자료형 | pandas 라이브러리 |
| **구조** | 값들의 단순한 나열 | 인덱스(index) + 값(value)의 구조 |
| **데이터 타입** | 한 리스트에 여러 자료형 가능 ([1, 'a', 3.5]) | 한 시리즈는 보통 하나의 자료형으로 통일 (int, float, str 등) |
| **인덱스** | 0, 1, 2, $\cdots$ 기본 인덱스만 있음 | 인덱스를 사용자가 지정 가능 (index=['a','b','c']) |
| **벡터 연산** | 불가능 (반복문으로 직접 계산해야 함) | 가능 (NumPy 기반으로 빠른 연산 수행) |
| **통계 함수** | 없음 (직접 작성해야 함) | 평균, 합계, 표준편차 등 통계 메서드 내장 (.mean(), .sum() 등) |
| **예시 코드** | lst = [10, 20, 30] | import pandas as pd $\newline$ s = pd.Series([10, 20, 30]) |

| **구분** | **.loc[]** | **.iloc[]** |
| --- | --- | --- |
| **약자** | location | integer location |
| **기반** | 라벨(Label) 기반 | 정수(Integer) 기반 |
| **행 선택** | `df.loc['a']` → 'a' 인덱스의 행 | `df.iloc[0]` → 첫 번째(0번째) 행 |
| **열 선택** | `df.loc[:, 'A']` → 'A' 열 선택 | `df.iloc[:, 0]` → 첫 번째(0번째) 열 선택 |
| **범위 선택** | `df.loc['a':'c']` → 'a'~'c' 포함 | `df.iloc[0:2]` → 0~1 (마지막 포함 X) |
