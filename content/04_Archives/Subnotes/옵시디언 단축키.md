# 옵시디언 주요 단축키 및 마크다운

옵시디언 활용 시 문서 작성 효율성을 높여주는 주요 단축키와 마크다운 문법을 정리함 (Windows 기준).

## 1. 기본 편집 및 마크다운
- **볼드체**: `**텍스트**` (또는 `Ctrl + B`)
- **이탤릭체**: `*텍스트*` (또는 `Ctrl + I`)
- **취소선**: `~~텍스트~~`
- **하이라이트**: `==텍스트==`
- **제목(Heading)**: `#` 부터 `######` 까지 입력 후 스페이스 (또는 `Ctrl + 1~6`)
- **인용구**: `>`
- **코드 블록**: 백틱 3개(\`\`\`) 입력

## 2. 링크 및 문서 조작
- **내부 링크(위키링크) 생성**: `[[`
- **외부 웹 링크 생성**: `[보여줄 텍스트](URL)`
- **제목(Heading)으로 링크**: `[[노트 제목#제목]]`
- **특정 블록(문단)으로 링크**: `[[노트 제목^]]`
- **새 노트 생성**: `Ctrl + N`
- **새 탭 열기**: `Ctrl + T`
- **탭 닫기**: `Ctrl + W`
- **탭 전환**: `Ctrl + Tab` 또는 `Ctrl + Shift + Tab`

## 3. 화면 및 UI 관리
- **명령어 팔레트 열기**: `Ctrl + P` (모든 기능 및 단축키 검색 가능)
- **빠른 전환기 (노트 검색 및 이동)**: `Ctrl + O`
- **그래프 뷰 열기**: `Ctrl + G`
- **읽기 모드 / 편집 모드 전환**: `Ctrl + E`
- **라이브 프리뷰 / 소스 모드 전환**: `Ctrl + P`에서 `Toggle Live Preview/Source mode 검색 (자주 쓰면 단축키 지정 권장)
  - *💡 팁: 토글이나 콜아웃 편집 시 커서가 닿을 때마다 글 상하 간격이 덜컥거리며 벌어지는 것이 불편하다면 '소스 모드'로 고정하거나 전환하여 사용하세요.*

## 4. 리스트 및 접기 (Folding)
- **불릿 리스트**: `- ` (하이픈 + 스페이스)
- **번호 리스트**: `1. ` (숫자 + 마침표 + 스페이스)
- **체크박스**: `- [ ] ` (토글 단축키: `Ctrl + Enter` 또는 `- [x]`)
- **들여쓰기/내어쓰기**: `Tab` / `Shift + Tab`
- **토글 접기/펴기**: `Ctrl + 방향키 위/아래` (리스트 및 제목에서 작동)
- **💡 기존 텍스트를 리스트 토글 안으로 넣기**: 상단에 `- 제목`을 적고, 아래 들어갈 여러 줄의 텍스트를 모두 드래그하여 선택한 뒤 `Tab`을 누르면 한 번에 들여쓰기되며 토글 안으로 들어갑니다.

## 5. 콜아웃 (부분 노트)
- **기본 문법**: `> [!유형] 제목`
- **토글형(접기) 콜아웃**: `> [!tip]- 제목` (처음에 접힌 상태) 또는 `> [!tip]+ 제목` (펼쳐진 상태)
- **지원 콜아웃 유형(태그) 목록**:
  - `note` — 📝
  - `info` — ℹ️
  - `todo` — ☑️
  - `tip` — 💡
  - `summary` — 📄
  - `success` — ✅
  - `question` — ❓
  - `warning` — ⚠️
  - `fail` — ❌
  - `error` — ⚡
  - `bug` — 🐛
  - `example` — 🧪
  - `quote` — 💬
- **💡 기존 텍스트를 콜아웃 안으로 넣기**: 상단에 `> [!info] 제목`을 적고, 아래 들어갈 기존 텍스트(여러 줄)를 모두 드래그하여 선택한 뒤, `Ctrl + P`(명령어 팔레트)에서 **"Toggle blockquote(인용구 켜기/끄기)"**를 실행하면 선택한 모든 줄 앞에 `>` 기호가 한 번에 붙어 콜아웃 안으로 쏙 들어갑니다.
