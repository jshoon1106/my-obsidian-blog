## 다른 표에 있는 데이터끼리 서로 연결하고 싶은 적이 있으셨나요? 잘 찾아오셨어요! Notion의 관계형 속성은 서로 다른 데이터베이스에 있는 항목 간의 관계를 나타내도록 고안되었답니다 🛠

한 회사가 다음 두 가지 데이터베이스를 사용한다고 가정해 봅시다 😉

- 고객을 관리하는 고객 데이터베이스

어느 고객이 어떤 품목을 구매했는지, 반대로 어느 품목을 어떤 고객이 구매했는지 알 수 있습니다. 관계형 속성을 활용하면 가능합니다!

![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F2ZxBndJzurrMDC8TGewWRu%2F6d9f33c3cb998233bda8fa3d3d525ab4%2Ftwo_database_relation.png&w=3840&q=75)

- 위 두 표의 `↗ 구매 품목`과 `↗고객` 열은 모두 관계형 속성이며, 다른 데이터베이스 속성과 같은 방식으로 추가할 수 있습니다.
- **고객** 데이터베이스에 고객이 구매한 품목을 추가하면, 해당 품목을 구매한 고객이 `품목` 데이터베이스의 **↗ 고객** 열에 자동으로 나타납니다.
- **동네 데이터베이스**와 **레스토랑 데이터베이스**를 연결하면 어떤 레스토랑이 어느 동네에 있는지 한눈에 확인할 수 있습니다.
- **회의록 데이터베이스**와 **고객 데이터베이스**를 연결하면 고객별 회의록에 빠르게 접근할 수 있습니다.
- **작업 데이터베이스**와 **프로젝트 데이터베이스**를 연결하면 프로젝트의 하위 작업과 작업의 상위 프로젝트를 파악할 수 있습니다.
- **채용 후보자 데이터베이스**와 **면접관 데이터베이스**를 연결하면 어느 면접관이 어느 후보자와 면접을 진행했는지 쉽게 파악할 수 있습니다.

관계형 속성을 설정하려면 두 개의 데이터베이스가 필요합니다. 위의 **고객**과 **품목** 데이터베이스를 예로 들어볼게요.

1. **고객** 데이터베이스에 새로운 열/속성을 추가하고 **구매한 항목**과 같이 이름을 붙여주세요.
2. `관계형`을 검색하세요.
3. 그 다음, 관계형을 생성할 데이터베이스를 검색하세요.
![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F18Zayw93oSm3IVZMBgFp2n%2Fb548900432569be6f49355bfe949a53f%2FChoose_related_database.png&w=3840&q=75)
연결된 데이터베이스 선택하기
4. 관계형 미리보기가 나타납니다. 이 예시에서는 고객 데이터베이스 안에 품목 데이터베이스 관계형을 생성했습니다.
5. 파란색 `관계형 추가` 버튼을 클릭해 완료하세요.
![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F2FBfKuKWYOZrWw5HS0WJR%2F05b51c55089212b4df02490f0aabf989%2Fone_way_relation.png&w=3840&q=75)
일방향 관계형
6. 이제 한 관계형 열의 셀을 클릭하면 다른 데이터베이스의 항목을 검색하고 열에 추가할 수 있는 메뉴가 나타납니다.
    - 항목을 추가하려면 목록에서 이름을 클릭하세요. 항목을 제거하려면 오른쪽의  버튼을 클릭하세요.

![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F65e1CeRlarITG5XsBh2ZNB%2F3fa0317338ccd0a1c725abc10cc1d880%2FRelate_page.png&w=3840&q=75)

관계형 페이지 추가

**팁:** 연결된 데이터베이스를 변경하려면 해당 속성의 유형을 `관계형`으로 다시 선택하세요. 새 데이터베이스를 선택하는 메뉴가 나타납니다.

관계형은 기본적으로 일방향입니다. 하지만 양방향 동기화도 가능합니다.

양방향 관계형에서는 내용을 편집하면 양쪽 데이터베이스에 적용됩니다. 예를 들어, **품목** 데이터베이스의 관계형 열에 고객을 추가하면, 해당 변경 사항이 **고객** 데이터베이스에도 반영됩니다.

7. 새로운 관계형 속성을 만들기 위해서는 위에서 설명된 단계에 따라 진행하세요.
8. `[연결된 데이터베이스]에 표시` 토글을 클릭하세요. 예시에서는 `항목 데이터베이스에 표시`가 됩니다.
9. 관계형에 이름을 지정하세요.
10. 아래의 양방향 관계형 미리보기를 확인하세요. 이 예시에서는 고객 데이터베이스에서 항목 데이터베이스의 관계형을, *그리고* 항목 데이터베이스에서 고객 데이터베이스의 관계형을 생성했습니다.
11. 파란색 `관계형 추가` 버튼을 클릭해 양쪽에 새로운 관계형 속성을 추가하는 것을 완료하세요.

![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F7gQ7x6McJEI2L2PiOgdlbz%2Fc7054e7e44f232375f218618130c831a%2Ftwo_way_relation.png&w=3840&q=75)

양방향 관계형

데이터베이스 관계형 속성은 한 데이터베이스의 페이지를 다른 데이터베이스 속성의 값으로 추가해 줍니다.

- 관계형 열의 페이지도 다른 페이지처럼 열고 편집할 수 있습니다. 관계형 열의 페이지를 클릭하고, 팝업이 나타나면 해당 페이지를 다시 클릭하세요.
- 오른쪽의 를 클릭하면 연결된 페이지를 제거할 수도 있습니다.
- 관계형 속성에 해당하는 페이지의 수를 제한할 수 있습니다. `1개 페이지` 또는 `제한 없음` 둘 중에서 선택하세요.
- `1개 페이지`로 제한하면 데이터베이스 사용자들이 관계형에서 1개의 페이지만 선택할 수 있습니다. 1:1 관계가 되어야 하는 경우 유용합니다. 예를 들어, 각 구매 항목 별로 발주 번호가 1개씩만 연결되어야 하는 경우 사용하세요.

데이터베이스 페이지에서 관계 표시 방법을 변경하려면 다음과 같이 진행하세요:

12. 데이터베이스 페이지에서 관계를 클릭하세요.

### 관계형 표시 속성 사용자 지정

데이터베이스에서 관계형을 설정할 때 링크된 페이지의 특정 속성을 표시하도록 선택할 수 있습니다. 예를 들어, 회사에는 자주 묻는 질문(FAQ) 데이터베이스가 있다고 가정해 볼게요. 각 FAQ는 해당 질문에 대한 자세한 설명이 담긴 페이지와 연결되는 관계형이 있습니다. 각 페이지의 소유자를 볼 수 있도록 설정하면 더 궁금한 점이 있을 때 누구에게 문의해야 하는지 알 수 있겠죠. FAQ 데이터베이스를 설정하여 관련 페이지와 함께 소유자가 표시되도록 할 수 있습니다.

방법은 다음과 같습니다.

13. 해당 속성 옆의 필드를 클릭하여 페이지를 링크하고 → `••` 아이콘을 클릭하세요.
14. 나타나는 메뉴에서 관련 데이터베이스의 속성을 `관계형에 표시하기` 또는 `관계형에 숨기기`에 드래그하세요.
15. 조정을 완료하면, 원하는 속성이 관계형 필드에 표시됩니다. 이는 현재 데이터베이스의 모든 페이지에 적용됩니다.



관계형 표시 속성 사용자 지정

하나의 데이터베이스 안에서 두 항목을 연결하고 싶으신가요? 예를 들어, 작업 데이터베이스 안에서 관련된 두 작업을 서로 연결하는 경우가 있겠죠.

16. 우선 새로운 관계형을 생성하세요.
17. 이제 데이터베이스가 같은 `이 데이터베이스`와 연결됩니다.
    - 데이터베이스를 데이터베이스 자체와 연관시킬 때, 필수적으로 속성을 복제하는 `양방향 관계형` 토글은 **끄는** 것이 좋습니다.

![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F6gwOO6BTwzkeF5x4vnab8z%2Ff9dac92f577d9a256149e04ac482a379%2FRelate_to_self.png&w=3840&q=75)

롤업을 사용하면 관계형을 기반으로 데이터베이스의 데이터를 종합할 수 있습니다. 위의 고객과 품목 예시로 돌아가, 고객이 구매한 품목을 기준으로 각 고객의 지출 금액을 알고 싶다고 가정해 봅시다.

18. 새로운 열/속성을 추가하고, `속성 유형` 메뉴에서 `롤업`을 선택하세요. 롤업 내용을 잘 나타내는 이름을 지어주세요.

![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F1ipgtMiHM74VIswzAP6faF%2Fe8435d2978687b0ab033ad857521bea0%2FRollup_step_1.png&w=3840&q=75)

- 이 예시에서는 `구매 품목` 관계형 속성을 선택한 후, `가격` 속성을 선택하세요. 그 다음, `합계` 계산을 선택하세요.
    - 이 롤업을 적용하면 각 고객에 연결된 모든 구매 품목의 가격 합계가 롤업 열에 나타납니다.

![](https://www.notion.com/_next/image?url=https%3A%2F%2Fimages.ctfassets.net%2Fspoqsaf9291f%2F5rFyqYW5Tv4rRDfed7VcLF%2F3606f3748ffdad67272099b5fc99fa0b%2FRollup_step_2.png&w=3840&q=75)

롤업에는 다양한 계산을 사용할 수 있습니다. 하나씩 설명해 드릴게요.

- `원본 표시: `연결된 모든 페이지를 하나의 셀에 표시합니다. 관계형 속성과 같은 내용을 나타냅니다.
- `고유한 값 표시: `연결된 모든 페이지의 고유한 속성값을 중복 없이 나타냅니다.
- `모두 세기: `연결된 모든 페이지에서 선택한 속성의 값 개수를 나타냅니다.
- `값 세기`: 연결된 모든 페이지에서 선택한 속성의 비어있지 않은 값 개수를 나타냅니다.
- `중복 제외 모두 세기: `연결된 모든 페이지에서 선택한 속성의 값 개수를 중복 없이 나타냅니다.
- `빈 값 세기: `결된 모든 페이지 중 선택한 속성이 비어있는 페이지의 개수를 계산합니다. 예를 들어, 고객의 구매 품목 중 가격 속성을 롤업했을 때, 1개 품목의 가격이 비어있다면 롤업 열에 1이 나타납니다.
- `비어 있지 않은 값 세기: `연결된 모든 페이지 중 선택한 속성이 비어있지 않은 페이지의 개수를 표시합니다.
- `빈 값 세기(%): `연결된 모든 페이지 중 선택한 속성이 비어있는 페이지의 개수를 백분율로 표시합니다.
- `비어 있지 않은 값 세기(%): `연결된 모든 페이지 중 선택한 속성이 비어있지 않은 페이지의 개수를 백분율로 표시합니다.

**이러한 롤업 계산은 **`**숫자**`** 속성**에서만 이용 가능합니다.

- `합계: `연결된 숫자 속성값의 합계를 표시합니다(위 예시의 경우입니다).
- `평균: `연결된 숫자 속성값의 평균을 표시합니다.
- `중앙값: `연결된 숫자 속성값의 중앙값을 표시합니다.
- `최소: `연결된 숫자 속성값 중 최솟값을 표시합니다.
- `최대: `연결된 숫자 속성값 중 최댓값을 표시합니다.
- `범위: `연결된 숫자 속성값 중 최솟값과 최댓값 사이의 범위를 표시합니다(`최댓값` - `최솟값`).

**이러한 롤업 계산은 **`**날짜**`** 속성에서만 이용 가능합니다.**

- `가장 이른 날짜: `연결된 모든 페이지의 날짜 속성에서 가장 이른 날짜/시간을 표시합니다.
- `최근 날짜: `연결된 모든 페이지의 날짜 속성에서 가장 최근 날짜/시간을 표시합니다.
- `날짜 범위: `연결된 모든 페이지의 날짜 속성에서 가장 이른 날짜와 가장 최근 날짜 사이의 기간을 표시합니다.

표와 보드 보기에서 롤업 열의 값을 계산해 전체 데이터베이스의 합계, 범위, 평균 등을 파악할 수 있습니다.

- 고객 표에서 `주문 총계` 속성을 클릭합니다.
- 나타나는 메뉴에서 `계산` → `옵션 더 보기`를 선택합니다.
- `합계`를 선택합니다.
