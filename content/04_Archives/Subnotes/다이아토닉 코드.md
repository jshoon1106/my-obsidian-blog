### 1. 정의 (무엇인지)
- 특정 음계의 구성음만을 사용하여 3도 간격으로 쌓아 만든 7개의 기본 코드 집합

### 2. 의의 (왜 알아야 하는지)
- 해당 조(Key) 안에서 자연스럽게 어울리는 코드들의 기본 라이브러리를 제공하여 코드 진행 구성과 곡 분석의 뼈대가 됨

### 3. 실제 예시 및 원리

#### C Major 기준 다이아토닉 7화음

| 도수 | 화음 | 역할/기능 |
| --- | --- | --- |
| $I\text{M7}$ | CM7 | 으뜸화음 (Tonic) - 안정 |
| $ii7$ | Dm7 | 버금딸림화음 대리 (Subdominant) - 이행 |
| $iii7$ | Em7 | 으뜸화음 대리 (Tonic substitute) |
| $IV\text{M7}$ | FM7 | 버금딸림화음 (Subdominant) - 변화 |
| $V7$ | G7 | 딸림화음 (Dominant) - 긴장 |
| $vi7$ | Am7 | 으뜸화음 대리 (Tonic substitute) |
| $vii^\circ7$ | Bm7♭5 | 딸림화음 대리 (Dominant substitute) |
