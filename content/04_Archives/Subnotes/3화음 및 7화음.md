### 1. 정의 (무엇인지)
- **3화음**: 근음 위로 3도씩 2개의 음을 쌓은 3개 음의 화음
- **7화음**: 3화음 위에 3도 음을 하나 더 쌓은 4개 음의 화음

### 2. 의의 (왜 알아야 하는지)
- 3화음은 모든 코드의 가장 기초적인 골격을 형성하며, 7화음은 장르별(재즈, 팝, 시티팝 등) 세련되고 풍부한 텐션감을 부여함

### 3. 실제 예시 및 원리

#### 3화음 종류

| 분류 | 구성음 관계 | 기호 예시 |
| --- | --- | --- |
| 장3화음 | 근음 + 장3도 + 완전5도 | C |
| 단3화음 | 근음 + 단3도 + 완전5도 | Cm |
| 증3화음 | 근음 + 장3도 + 증5도 | Caug |
| 감3화음 | 근음 + 단3도 + 감5도 | Cdim |

#### 7화음 종류

| 분류 | 구성음 관계 | 기호 예시 |
| --- | --- | --- |
| 장7화음 | 장3화음 + 장7도 | CM7 |
| 딸림7화음 | 장3화음 + 단7도 | C7 |
| 단7화음 | 단3화음 + 단7도 | Cm7 |
| 반감7화음 | 감3화음 + 단7도 | Cm7♭5 |
| 감7화음 | 감3화음 + 감7도 | Cdim7 |
