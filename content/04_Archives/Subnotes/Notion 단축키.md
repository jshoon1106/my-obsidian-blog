# [Notion 키보드 단축키](https://www.notion.com/ko/help/keyboard-shortcuts)

이 가이드는 노션에서 마우스를 사용하지 않고도 효율적으로 작업을 수행할 수 있도록 키보드 및 마크다운 단축키에 대한 포괄적인 개요를 제공합니다.

## 자주 사용하는 단축키

- `Cmd/Ctrl + P`: 검색을 열거나 최근에 본 페이지로 이동합니다.
- `Cmd/Ctrl + N`: 새 페이지를 만듭니다.
- `Cmd/Ctrl + Shift + N` (또는 `Cmd/Ctrl + 클릭`): 새 노션 창을 엽니다.
- `Cmd/Ctrl + [`: 이전 페이지로 돌아갑니다.
- `Cmd/Ctrl + ]`: 다음 페이지로 이동합니다.
- `Cmd/Ctrl + Shift + L`: 다크 모드를 켜거나 끕니다.

## 데스크톱 키보드 단축키

- `Cmd/Ctrl + O`: 브라우저에서 새 탭을 엽니다.
- `Cmd/Ctrl + Shift + K`: 페이지를 복제합니다.

## :이모지🎇

- `**: **``+ 이모지` : 🍎, 👏
- `Windows 키 + . (또는 ;)` : 이모지 선택

## 마크다운 스타일

노션은 빠른 텍스트 서식을 위해 마크다운을 지원합니다:

- **굵게**: `*텍스트**` 또는 `__텍스트__`를 입력합니다.
- *기울임꼴*: `텍스트*` 또는 `_텍스트_`를 입력합니다.
- `인라인 코드`: ``텍스트``를 입력합니다.
- ~~취소선~~: `~~텍스트~~`를 입력합니다.

### 마크다운으로 블록 만들기

- **글머리 기호 목록**: `-` 또는 `+` 뒤에 공백을 입력합니다.
- **할 일 체크박스**: `[]` (사이에 공백 없음) 뒤에 공백을 입력합니다. :
- **번호 매기기 목록**: `1.` 또는 `1)` 뒤에 공백을 입력합니다.
- **토글 목록**: `>` 뒤에 공백을 입력합니다.
- **인용 블록**: `"` 뒤에 공백을 입력합니다.
- **제목 1**: `#` 뒤에 공백을 입력합니다.
- **제목 2**: `##` 뒤에 공백을 입력합니다.
- **제목 3**: `###` 뒤에 공백을 입력합니다.
- **구분선**: 새 줄에 `--` (하이픈 3개)를 입력합니다.

## 콘텐츠 생성 및 꾸미기

- **사람 멘션**: `@` 뒤에 이름을 입력합니다.
- **페이지 멘션**: `@` 뒤에 페이지 이름을 입력합니다.
- **날짜 멘션**: `@` 뒤에 날짜(예: "내일", "다음 주", 특정 날짜)를 입력합니다.
- **알림 설정**: `@remind` 뒤에 날짜/시간을 입력합니다.
- **기존 페이지에 연결**: `` 뒤에 페이지 이름을 입력합니다. [[Notion 단축키 
- **하위 페이지 만들기**: `+` 뒤에 새 하위 페이지 이름을 입력합니다.
- **댓글**: 텍스트를 선택하고 `Cmd/Ctrl + Shift + M`을 누릅니다.
- **복제**: 모든 블록에서 `Cmd/Ctrl + D`를 누릅니다.
- **삭제**: 블록을 선택하고 `Delete` 또는 `Backspace`를 누릅니다.
- **이동**: 블록을 드래그 앤 드롭합니다.
- **블록 유형 변경**: `Cmd/Ctrl + /`를 눌러 블록 메뉴를 엽니다.
- **새 페이지로 전환**: 텍스트를 선택하고 `Cmd/Ctrl + Shift + P`를 사용합니다.
- **텍스트로 전환**: 제목이나 헤더에서 `Cmd/Ctrl + Shift + T`를 누릅니다.

## 블록 편집 및 이동

- **블록 선택**: 블록 옆에 있는 점 6개 아이콘을 클릭합니다.
- **여러 블록 선택**: `Shift + 클릭`하거나 커서를 드래그합니다.
- **블록 이동**: 점 6개 아이콘을 드래그 앤 드롭합니다.
- **블록 복제**: 블록을 선택하고 `Cmd/Ctrl + D`를 누릅니다.
- **블록 삭제**: 블록을 선택하고 `Delete` 또는 `Backspace`를 누릅니다.

## 슬래시 명령어 ( / )

`/` 명령어는 다양한 콘텐츠 블록을 빠르게 삽입하고 작업을 수행하는 강력한 도구입니다.

### 기본 블록

- `/텍스트`
- `/페이지`
- `/할일`
- `/h1`, `/h2`, `/h3`
- `/글머리 기호`
- `/번호 매기기`
- `/토글`
- `/인용`
- `/구분선`
- `/콜아웃`

### 인라인 명령어

- `/멘션` (사람 또는 페이지 멘션)
- `/날짜` (날짜 삽입)
- `/방정식` (인라인 방정식 삽입)

### 미디어 및 임베드

- `/이미지`
- `/pdf`
- `/비디오`
- `/오디오`
- `/코드`
- `/파일`
- `/임베드` (다른 앱의 콘텐츠 임베드)

### 고급 블록

- `/목차`
- `/템플릿 버튼`
- `/브레드크럼`
- `/동기화` (동기화된 블록 만들기)

### 데이터베이스 블록

- `/표` (전체 페이지 또는 인라인)
- `/보드`
- `/갤러리`
- `/목록`
- `/캘린더`
