💻 윈도우 필수 유틸 정리

가볍고 실사용 위주로 정리한 프로그램 목록입니다.과한 최적화보다는 안정성과 편의성 중심 구성입니다.


📂 파일 검색
Everything
→ 초고속 파일 검색 유틸리티
→ NTFS 기반 인덱싱으로 거의 즉시 검색
→ 파일명 검색에 특화 (내용 검색은 제한적)
→ 가볍고 필수에 가까운 프로그램


🌐 브라우저
네이버 웨일
→ 국내 웹 서비스 최적화
→ 사이드바·번역·화면 캡처 등 편의 기능 우수
→ 크로미움 기반이라 크롬 확장 프로그램 대부분 사용 가능
→ 단, 구버전 환경에서는 호환성을 장담하기 어려움 (최신 OS 권장)


🛠 시스템 관리
Microsoft PC Manager
→ 마이크로소프트 공식 PC 관리 도구
→ 저장 공간 정리, 시작 프로그램 관리, 보안 점검 지원
→ 과도한 최적화 프로그램 대신 가볍게 쓰기 좋음

구라제거기
→ 국내 웹사이트 이용 시 설치되는 보안 프로그램(ActiveX, 보안 EXE 등) 정리 특화
→ 은행/공공기관 사이트 사용 후 정리용으로 유용

Malware Zero Kit (MZK)
→ 무료 악성코드 제거 도구
→ 설치형이 아닌 수동 실행 기반 검사 방식

Geek Uninstaller
→ 프로그램 삭제 후 레지스트리 및 잔여 파일까지 정리
→ 포터블(무설치) 사용 가능


📦 압축 프로그램
반디집
→ 무료 버전 제공
→ 직관적인 UI, 다양한 포맷 지원

7-Zip
→ 완전 무료·오픈소스
→ 가볍고 압축 효율 우수

다집
→ 무료·가벼움
→ ALZ 포맷 지원 (구형 국내 압축 파일 대응용)


🎬 미디어 플레이어
팟플레이어
→ 가볍고 기능 다양
→ 코덱 내장, 세부 설정 풍부
→ 광고는 있으나 영어 버전 설치 권장
→ 설치 후 설정에서 한국어로 언어 변경 가능
(Preferences → General → Language)


💻 하드웨어 정보
CPU-Z
→ CPU, RAM, 메인보드 정보 확인
→ 실시간 클럭·메모리 정보 모니터링 가능


🌙 편의 유틸
Twinkle Tray
→ 다중 모니터 밝기 개별 조절
→ DDC/CI 지원 모니터에서 정상 작동


📄 오피스
한컴독스
→ 웹 기반 오피스 서비스
→ 네이버 연동 시 무료 사용 가능
→ HWP 파일 호환성 강점


🛡 백신
Microsoft Defender
→ 최근 탐지 성능 많이 향상
→ 일반 사용자라면 단독 사용으로도 충분한 수준
→ 추가 백신 설치는 취향 영역


🎮 GPU 관리
MSI Afterburner
→ GPU 오버클럭 및 팬 커브 설정
→ 온도·클럭·사용률 모니터링 기능 제공


🎥 비디오 변환
샤나 인코더
→ 다양한 비디오 포맷 변환 (MP4, MKV, AVI 등)
→ 간편한 UI, 고속 변환, 자막 삽입 가능
→ 비트레이트·해상도·프레임레이트 등 고급 설정 지원
→ FFmpeg 기반 인코더
