- **1. 동기화 솔루션 비교**
  - **Syncthing (로컬 P2P)**
    - 장점: 완전히 무료, 실시간 동기화, 설정 폴더(`.obsidian/`) 동기화 지원으로 모바일 AI 설정 공유 용이
    - 단점: 데스크톱과 모바일 기기가 동시에 켜져 있어야 동기화 가능
  - **Remotely Save (클라우드 API)**
    - 장점: 구글 드라이브 직접 연동 가능, 기기가 동시에 켜져 있을 필요 없음
    - 단점: 실시간이 아닌 동기화 주기 대기 필요, 설정 폴더 동기화 시 오류 빈번하여 모바일 AI 개별 세팅 필요

- **2. Syncthing 설정 가이드 (Windows - Android)**
  - **데스크톱(Windows) 설정**
    1. Syncthing 공식 홈페이지에서 윈도우용 프로그램 설치 및 실행
    2. 웹 GUI(http://localhost:8384) 접속
    3. 옵시디언 볼트 폴더(`C:\MYDrive\Workspace-Obsidian`)를 공유 폴더로 등록
  - **모바일(Android) 설정**
    1. 구글 플레이 스토어에서 Syncthing 앱 설치
    2. 데스크톱 웹 GUI에서 [기기 추가]를 눌러 모바일 기기 ID 등록 및 상호 승인
    3. 모바일에서 옵시디언 볼트를 보관할 내부 저장소 폴더 지정 및 데스크톱 공유 폴더 수락
  - **동기화 제외 필터 설정**
    - 불필요한 캐시 파일 동기화 방지를 위해 공유 폴더 설정 내 [무시 패턴] 탭에 아래 내용 추가:
      ```text
      (?d).obsidian/workspace
      (?d).obsidian/workspace.json
      (?d).obsidian/backups
      (?d).trash
      ```

- **3. Remotely Save 설정 가이드 (Google Drive)**
  - **플러그인 설정**
    1. 데스크톱 및 모바일 옵시디언 앱에서 커뮤니티 플러그인 `Remotely Save` 설치 및 활성화
    2. 플러그인 설정의 [Sync Method] 항목에서 `Google Drive` 선택
    3. [Auth] 버튼을 눌러 구글 계정 로그인 및 API 사용 승인
  - **동기화 트리거 설정**
    - [Run Options]에서 `Sync on Startup` 활성화하여 앱 실행 시 자동 동기화 처리
  - **설정 제외 권장**
    - 충돌 예방을 위해 모바일 환경 설정 폴더(`.obsidian/`)는 동기화에서 제외하거나 원격 저장소 경로를 별도 분리하여 운영 권장

- **4. 모바일 AI 플러그인 사용 가이드**
  - **Copilot 및 Smart Connections 활용**
    - 모바일 옵시디언에서 사이드바를 확장하여 AI 챗 창 이용 가능
  - **성능 한계 대응**
    - 모바일의 하드웨어 리소스(RAM/CPU) 한계로 대용량 볼트 인덱싱 및 로컬 임베딩 연산 시 앱 지연 혹은 종료 현상 발생 가능
    - 원활한 사용을 위해 대규모 임베딩 연산은 데스크톱에서 사전 완료 후 결과 파일만 동기화하여 사용을 권장
  - **동기화 방식별 AI 설정 권장 사항**
    - **Syncthing 적용 시**: 데스크톱의 API 키 및 설정이 모바일로 자동 공유되므로 추가 세팅 없이 즉시 사용
    - **Remotely Save 적용 시**: 모바일 앱 내 AI 플러그인 설정 창에서 API 키를 개별적으로 기입 및 활성화 필요

- **5. 모바일 AI 에이전트 연동 및 모델 선택 대화 방안**
  - **PC 에이전트 원격 연동**
    - **텔레그램/디스코드 봇**: PC에서 백그라운드 봇 스크립트를 실행하여 모바일 메신저로 대화 및 볼트 제어 명령 전송
    - **Open-WebUI + Tailscale**: PC 챗 웹UI를 가상 전용망(Tailscale)을 통해 모바일 웹/PWA로 접속하여 이용
  - **PC 전원 제약 극복 방안**
    - **WOL (Wake-on-LAN)**: 모바일 앱으로 PC 전원을 원격 부팅 후 자동 실행 서비스로 에이전트 구동
    - **클라우드 VPS**: 24시간 가동 서버에 봇 프로세스를 올리고 볼트 파일(Git 등)을 주기적으로 동기화하여 무중단 이용
  - **모바일 파일/디렉토리 기반 모델 선택 대화 프로그램**
    - **Obsidian Mobile + Copilot / Smart Connections**: 모바일 앱 내에서 볼트 파일 기반 시맨틱 검색(RAG) 및 Gemini, GPT-4o, Claude 등 모델 선택 대화 지원
    - **Chatbox Mobile**: 모바일 파일/클라우드 문서를 첨부하고 API 키 연동을 통해 다양한 모델 교체 대화 수행
