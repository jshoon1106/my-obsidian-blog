## 1. 파일 및 디렉토리 확인과 이동

- `pwd`: 현재 위치한 디렉토리의 절대 경로 확인
- `ls`: 현재 디렉토리의 파일 및 폴더 목록 확인 (`ls -al`로 상세 확인)
- `cd [경로]`: 원하는 디렉토리로 이동

## 2. 파일 조작 및 관리

- `mkdir [폴더명]`: 새로운 디렉토리 생성
- `mv [원본] [대상]`: 파일 이동 또는 이름 변경
- `cp [원본] [대상]`: 파일 또는 디렉토리 복사 (`cp -r`은 폴더 복사)
- `rm [파일명]`: 파일 삭제 (`rm -rf`는 폴더 강제 삭제)

## 3. 파일 내용 확인

- `cat [파일명]`: 파일 전체 내용 출력
- `head -n [숫자] [파일명]`: 파일의 앞부분 지정한 줄만큼 출력
- `tail -n [숫자] [파일명]`: 파일의 뒷부분 지정한 줄만큼 출력 (`tail -f`로 실시간 모니터링)

## 4. 압축 및 해제

- `tar -xvf [파일명.tar.gz]`: tar.gz 압축 해제
- `tar -czvf [파일명.tar.gz] [폴더]`: tar.gz 압축 실행
- `unzip [파일명.zip]`: zip 압축 해제

## 5. 파일 전송 및 권한

- `scp [파일] [사용자]@[IP]:[경로]`: 네트워크를 통한 파일 전송
- `chmod [권한] [파일]`: 파일 접근 권한 변경

> 💡 **HDFS 명령어 Tip**
리눅스 명령어 앞에 `hdfs dfs -`를 붙여 사용하면 대다수 유사하게 작동합니다. (예: `hdfs dfs -mkdir /myfolder`)

### `vi [파일명]` 또는 `vim [파일명]`

가장 많이 쓰이지만 익숙해지는데 시간이 조금 걸리는 표준 편집기입니다. 실행 후 **모드 전환**을 기억해야 합니다.

- **입력 시작**: 파일이 열린 상태에서 `i`를 누르면 하단에 `- INSERT --`가 뜨며 수정이 가능해집니다.
- **입력 종료**: 수정이 끝나면 `Esc` 키를 눌러 입력 모드를 빠져나옵니다.
- **저장 및 종료 (명령어 입력)**: `Esc`를 누른 상태에서 아래 명령어를 타이핑하고 `Enter`를 누릅니다.
    - `:wq` : 저장하고 종료
    - `:q!` : 저장하지 않고 강제 종료
    - `:w` : 종료하지 않고 저장만 하기

### `nano [파일명]`

`vi`가 너무 복잡할 때 사용할 수 있는 초보자 친화적인 편집기입니다. (화면 하단에 단축키 가이드가 항상 표시됨)

- **저장**: `Ctrl + O` 누른 뒤 `Enter`
- **종료**: `Ctrl + X`
