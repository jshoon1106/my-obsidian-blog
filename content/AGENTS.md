## 역할
+ 파일/폴더 계층 분석 및 체계적 지식망 연속성 유지
+ 옵시디언 Vault에 대한 기본 시스템 규칙 및 정책 정의

## 기본 시스템 규칙
0. 옵시디언 볼트에 대한 명령 실행 시, 환경 설정 파일(`AGENTS.md`(규칙), `index.md`(목차), `log.md`(작업 이력))을 백그라운드에서 열람함.
	* 현재 폴더 구조와 설정 파일의 기술이 일치하는지 확인함.
	* 목적: 이전 세션의 분류 체계, 규칙, 작업 이력 인지; 타 기기에서도 연속 작업 보장. 사용자가 명령 전 현재 환경과 일치하는지 질문하지 않아도 됨.
	* 현재 환경과 맞지 않거나 환경 설정 파일의 수정이 필요할 시 준수 사항:
		1. 해당 대화에서 바로 수정하지 않을 것
		2. 답변 시, 수정이 필요한 부분에 대한 내용을 공지할 것
	- log.md(작업 이력)에 대한 규칙:
		1. 볼트의 전체적인 구조 개편이 발생했을 때 수정
		2. 노트 통폐합, 새로운 노트 작성 등 빈번하게 발생하는 작업은 일일히 수정하지 않음
1. 환경 동기화 및 스킬: 에이전트와 시스템이 동일한 컨텍스트와 자동화 도구를 유지할 수 있도록 워크스페이스 표준 폴더(`.agents/`)를 관리:
	* 전역 스킬 (`.agents/skills/vault_automation/`): 전체 자동화 작업에 사용된 파이썬 스크립트와 실행 지침(`SKILL.md`)을 보관함.
	* 도메인 스킬 (`.agents/skills/finance_processor/` 등): 특정 영역(재무 등)에 국한되어 사용되는 스크립트와 지침을 보관함(특정 영역 경로 명시 포함).
	* 외부 확장 스킬: `AgentMemory`(맥락 유지), `Understand-Anything`(지식망 분석), `Claude-Video`(영상 요약), `Humanizer`(문체 교정)를 설치하여 필요시 조건부 발동함.
2. 통합 시스템 관리 원칙:
	1. 구조: Vault 최상위 레벨에서 'Hub & Spoke' 모델을 지향함. `index.md`를 전체 MOC로 두고, `01~04` 관리 영역에 요약/정제된 지식 노트를 배치하며, `04_Archives/Subnotes/` 폴더에 디테일과 원본 데이터(Raw Data)를 분리하여 보관함.
	2. 첨부파일 관리: 모든 첨부파일(이미지 등)은 기본적으로 `04_Archives/Attachment files` 폴더에 중앙 집중식으로 저장함.
	3. 노트 및 디렉토리의 생성, 삭제, 이동, 병합, 수정 시:
		- 내용 유실을 막기 위해 수정 전 노트를 먼저 읽고, 변경 계획을 명시적으로 고지하고 승인을 얻음.
	4. 인덱싱 및 목차 명세: 디렉토리 구조 및 다른 노트를 연결할 때, 잦은 변경에 대비해 텍스트 경로가 아닌 옵시디언 위키링크(`[[노트명]]`) 방식을 사용함. 목차 생성 시, 불필요한 목차를 생성하지 않고(예: 제목와 유사한 이름의 최상위 목차), 되도록이면 작은 분류 문법을 이용해 작성한다.
	5. 문체 및 양식: 노트 작성 시 이모티콘 사용을 지양하고, 짧고 간결한 명사체를 사용함(~ 보관, ~ 저장 등)(명사형 어미는 생략 가능하면 생략하기). 불필요한 메타데이터(파편화된 태그, 무의미한 type 등) 사용을 지양하며, 본문 위주의 작성을 지향함(웹 클리퍼 표준 속성 등 특수 목적 제외). 최소한의 분류 문법(`###`, `####`, `-`, `>`, `---` 등)을 활용하여 간결하게 명세함.
